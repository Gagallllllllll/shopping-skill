# Security

- The skill never logs in, creates accounts, buys, or asks for passwords, card or bank details. If you see it do any of this, open an issue.
- Web pages and listings are treated as untrusted data, never as instructions. If you find a page that makes the skill follow instructions written in it (prompt injection), please report it.
- Optional add-ons (Scrapling, Obscura, lbc) are pinned to exact versions and installed in their own folders; Obscura's download is checked against its published SHA-256.
- Report a vulnerability by opening an issue without exploit details, and ask for a private contact if needed.
